# 💰 Money Turbo Repository – Free Shorts Engine

A 100% free, AI-driven pipeline for building high-retention YouTube Shorts optimized for monetization.

## 📂 Project Structure

- `assets/brand/`: Core brand styling, hex colors, and custom fonts.
- `scripts/`: Production-ready 30-second scripts containing verified sources.
- `prompts/`: Standardized prompts for image and voice generation.
- `workflow.md`: The 1-hour-a-day standard operating procedure (SOP).

## ⚡ Quick Daily Routine
1. Grab the hook from `scripts/`.
2. Generate visuals via Bing Image Creator using `prompts/image_prompt.txt`.
3. Animate using Runway Gen-2 or Pika.
4. Generate natural audio via ElevenLabs using `prompts/voice_prompt.txt`.
5. Assemble and auto-caption in CapCut (9:16 vertical).
6. Upload to YouTube Shorts and track retention at the 2-second mark.

## 📜 Standards
All scripts must include verifiable source citations to adhere to YouTube advertiser-friendly guidelines.
